# MASTER BUILD PROMPT — BLINK: THE WORLD CHANGES WHEN YOU LOOK AWAY

You are an expert mobile-game designer, Flutter engineer, UI/UX designer, motion designer, sound designer, game-economy designer, and product engineer.

Build a complete polished Android mobile game called:

# BLINK

### The World Changes When You Look Away.

The game is a fast, visually beautiful cognitive challenge game where players must observe, remember, predict, detect changes, and discover hidden rules.

The game must feel like a premium modern mobile game with:

* smooth animations
* satisfying interactions
* polished transitions
* original fantasy/sci-fi visual identity
* gem-based rewards
* particles
* haptics
* sound effects
* progression
* daily challenges
* unlockable content
* changing gameplay mechanics

Do NOT copy copyrighted characters, artwork, icons, sounds, UI layouts, names, or assets from Clash of Clans, Subway Surfers, Candy Crush, or any other game.

* polish

Everything visual and gameplay-specific must be original.

# 1. CORE GAME IDEA

The player sees a scene for a short time.

The scene disappears or changes.

The player must answer what happened.

Examples:

* What changed?
* What disappeared?
* Which object moved?
* Which color changed?
* Which two objects swapped places?
* Which object was closest to another?
* What happened first?
* Where will this object move?
* Which rule is being followed?
* What is different from the previous scene?

The game should never feel like one repetitive memory test.

The challenge engine must continuously combine:

* visual memory
* spatial memory
* color recognition
* sequence memory
* prediction
* reaction
* pattern recognition
* attention
* rule discovery
* multi-tasking
